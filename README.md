# 🛡️ EcoWatch AI

Система обнаружения пожаров и дыма на видео в реальном времени на базе YOLOv8.

Работает с веб-камерой, IP-камерой (RTSP/HTTP), видеофайлом или захватом экрана.
Подтверждённые угрозы записываются в журнал со снимком и видеоклипом, а уведомления уходят в Telegram.

## Возможности

- **Без ложных «миганий».** Вероятности сглаживаются по времени, а инцидент
  начинается только после нескольких подряд опасных кадров и заканчивается после серии чистых.
  Если дым перерастает в пожар, это фиксируется в том же инциденте.
- **Инциденты, а не спам.** Одна угроза — одна запись в журнале (начало, конец, пиковая
  вероятность, снимок, клип) и одно уведомление в Telegram с настраиваемой паузой.
- **Фоновый мониторинг.** Видео обрабатывается в отдельном потоке: интерфейс не подвисает,
  а мониторинг продолжается при переключении вкладок и перезагрузке страницы.
- **Клипы с предзаписью.** В клип попадают несколько секунд *до* тревоги.
- **Переподключение к камере** при обрыве связи.
- **Консольный режим** для круглосуточной работы на сервере без браузера.
- Аналитика по периодам, тепловая карта активности, карта камер, экспорт журнала в CSV.
- Поддерживаются модели classify (как текущая `models/best.pt`) и detect (с рамками).

## Установка

Нужен Python 3.10 или новее.

```bash
python -m venv .venv
.venv\Scripts\activate          # Windows
source .venv/bin/activate       # Linux/macOS
pip install -r requirements.txt
```

### Настройка Telegram

Скопируйте `.env.example` в `.env` и заполните:

```ini
ECOWATCH_TG_TOKEN=123456:ABC...     # токен от @BotFather
ECOWATCH_TG_CHAT_ID=123456789       # ID чата, можно узнать у @userinfobot
```

Токен никогда не хранится в коде: файл `.env` исключён из git.

## Запуск

### Веб-интерфейс

```bash
streamlit run main.py
```

Или двойной клик по `run_app.bat` в Windows. Откроется http://localhost:8501.

### Консольный режим

```bash
python -m ecowatch 0                                   # веб-камера №0
python -m ecowatch rtsp://user:pass@192.168.1.10/live --record
python -m ecowatch video.mp4 --show                    # с окном предпросмотра
python -m ecowatch screen                              # захват экрана
python -m ecowatch report                              # отчёт за сегодня в Telegram
python -m ecowatch --help                              # все параметры
```

Ежедневный отчёт удобно отправлять по расписанию: через планировщик заданий Windows или cron.

## Настройка чувствительности

| Параметр | По умолчанию | Смысл |
|---|---|---|
| Порог вероятности | 0.65 | минимальная сглаженная вероятность опасного класса |
| Отрыв от 2-го класса | 0.15 | защита от неоднозначных кадров |
| Сглаживание | 0.35 | вес нового кадра: меньше — стабильнее, но медленнее реакция |
| Кадров для подтверждения | 4 | сколько опасных кадров подряд нужно для тревоги |
| Кадров для отбоя | 15 | сколько чистых кадров подряд завершают инцидент |

В веб-интерфейсе пороги меняются на лету, без перезапуска мониторинга.

## Обучение модели

**Классификация** (как у текущей модели): датасет из папок по классам.

```
dataset_detect/
├── train/ {fire, normal, smoke}/
└── val/   {fire, normal, smoke}/
```

```bash
python train.py --data dataset_detect
```

**Детекция с рамками** (рекомендуется: точнее и показывает, *где* огонь): датасет в формате YOLO.

```bash
python train.py --data fire_smoke/data.yaml --model yolov8s.pt --imgsz 640
```

Лучшие веса автоматически копируются в `models/best.pt`, а прежняя модель сохраняется
рядом как `best_<дата>.pt`.

## Структура проекта

```
main.py              точка входа Streamlit
train.py             обучение модели
ecowatch/
├── config.py        настройки и пороги (.env)
├── detector.py      обёртка YOLO: classify и detect
├── tracker.py       сглаживание и гистерезис → инциденты
├── monitor.py       фоновый цикл мониторинга
├── sources.py       камеры, потоки, файлы, экран
├── storage.py       журнал инцидентов (SQLite)
├── notifier.py      Telegram (в фоне)
├── recorder.py      клипы с предзаписью
├── overlay.py       отрисовка поверх видео
├── ui.py            веб-интерфейс
└── cli.py           консольный режим
tests/               тесты (pytest)
```

Данные хранятся в `data/`: база `ecowatch.db`, а также папки `snapshots/` и `clips/`.
Журнал старой версии (`detection_history.json`) импортируется автоматически при первом запуске.
